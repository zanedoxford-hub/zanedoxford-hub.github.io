3015ICT Trustworthy AI · Griffith · 2026

Prompt Injection Forensics in Large Language Models

Researched and simulated structural prompt injection attacks (naive, delimiter escape, context ignoring and fake completion) against a RAG summarisation pipeline running Qwen2.5-0.5B-Instruct. Built a forensic localiser that uses token-level cross-entropy spikes to pinpoint the exact span of an injected payload in an execution log.

3012ICT Cryptography · Griffith · 2026

Cryptanalysis & Python Crypto Toolkit

Broke classical ciphers and analysed modern ones, then built a Python toolkit that computes and explains the maths behind common cryptographic primitives.

  • Identified and broke a Vigenère cipher using Kasiski examination and Index of Coincidence, and a substitution cipher using trigram frequency analysis
  • Demonstrated why ECB mode leaks patterns and CBC does not by encrypting an image with OpenSSL; simulated an LFSR stream cipher; worked AES and RSA problems
  • Toolkit covers extended GCD, modular inverse, square-and-multiply, RSA, Diffie-Hellman, ElGamal, elliptic-curve point maths and PKCS#7 padding
