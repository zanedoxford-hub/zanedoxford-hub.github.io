# Zane Doxford: Cyber Security Portfolio

A plain HTML, CSS and JavaScript site with no build step. It runs free on GitHub Pages.

```
index.html               Home: about, skills, experience, contact
projects.html            Finished projects
progress.html            Progress tracker (reads assets/progress-data.js)
assets/style.css         All styling (colours are at the top)
assets/main.js           Menu, animations, progress rendering
assets/progress-data.js  EDIT THIS to update the Progress page
assets/Zane_Doxford_Resume.pdf   Public resume (phone number removed)
guides/                  Your private step-by-step project guides (not uploaded, see .gitignore)
```

Start with `guides/00-website-setup.md`.
